# CodeforcesFlow

A tool that will help you evaluate your skills in sports programming.

## Описание

CodeforcesFlow — это веб-приложение для оценки навыков в спортивном программировании.

## Структура проекта

- `server.js` — основной сервер на Express.js
- `db.js` — работа с базой данных SQLite
- `Back/` — бэкенд модули (аутентификация)
- `Front/` — фронтенд файлы (HTML, CSS, JS)
- `database.db` — база данных SQLite

## Запуск

```bash
node server.js
```

Сервер запустится на порту 3000: http://localhost:3000

## Технологии

- Node.js
- Express.js
- SQLite (better-sqlite3)
- HTML/CSS/JavaScript
